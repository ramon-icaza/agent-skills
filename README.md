# Набор скиллов для агентной разработки

Этот набор содержит скиллы, предназначенные для организованной работы агента по идее от прожарки до реализации и отчёта. Все скиллы написаны на русском языке.

## Список скиллов

| Скилл | Назначение |
|-------|------------|
| [`grill`](skills/grill/) | Прожарка идеи — критический разбор концепции, поиск слабых мест, уточнение целей и границ. Универсальный, применим в любой области. |
| [`handoff`](skills/handoff/) | Подготовка результата `grill` к передаче другому агенту. Форматирует заgrillованную идею в структурированное задание. |
| [`implement`](skills/implement/) | Реализация задачи: декомпозиция, выполнение подзадач субагентами, проверка через `review`, отчёт пользователю. |
| [`tdd`](skills/tdd/) | Разработка через тестирование: Red → Green → Review, циклическое устранение проблем. |
| [`review`](skills/review/) | Проверка кода на соответствие требованиям качества (баги, уязвимости, производительность, тесты, YAGNI и т.д.). |

## Предполагаемый порядок использования

1. Пользователь вызывает `grill` для прожарки идеи вместе с агентом.
2. (Опционально) Пользователь вызывает `handoff`, чтобы подготовить результат к передаче другому агенту.
3. Пользователь вызывает `implement`, передавая результат `handoff` (или задачу напрямую):
   - 3.1. Агент декомпозирует работу на подзадачи, определяет очередность и вызывает субагентов.
   - 3.2. Субагент определяет тип подзадачи: код → `tdd`, иное → прямое выполнение.
   - 3.3. После всех подзадач агент вызывает субагента для `review`. При проблемах планирует исправления и возвращается к 3.1.
   - 3.4. Агент выводит пользователю отчёт о проделанной работе.

`grill` универсален и может использоваться в любых задачах, не только в разработке. `handoff` после него опционален — в некоторых случаях `grill` самодостаточен.
